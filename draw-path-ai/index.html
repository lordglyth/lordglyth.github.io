What the AI is doing

Character mode uses semantic segmentation aimed at people/clothing/body regions. General mode uses scene segmentation. Those regions become clean boundaries; only the strongest internal photo edges are added for facial features, folds, and other useful details. The result is simplified and split into ordered paths for Line ▶. It is deliberately not a raw “trace every pixel edge” filter.
