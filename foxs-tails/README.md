# Fox's Tails

**Fox's Tails** is an original single-player fox adventure prototype built as a lightweight HTML5 game.

You play as **Saffron**, a young fox whose enchanted tail ribbons were scattered across Bramblewick after a storm cracked the old moon shrine. Instead of co-op mechanics, Saffron's own fox abilities handle traversal and puzzles: scent vision, a tail-swish interaction, sprinting, and environmental clues.

## Play

Open `index.html` in a modern browser, or visit the GitHub Pages path for this folder once Pages updates.

### Controls

- **WASD / Arrow keys** — move
- **Shift** — sprint
- **E** — interact / talk / use nearby objects
- **Q** — scent vision
- **Space** — tail-swish
- **Esc** — close dialogue / pause

Touch controls are included for phones and tablets.

## Current vertical slice

- Single-player fox character with animated movement
- Bramblewick village/forest map
- NPC dialogue and a small quest chain
- Three hidden Moon-Tail Ribbons to recover
- Scent-vision clue system
- Interactive shrine, bridge lever, berry bushes, signposts and villagers
- Simple collision, camera, particles, quest tracker and local save data
- Keyboard and touch controls
- No external art, libraries, tracking, or network dependency

## Direction

The project is intentionally its own game rather than a direct copy of another title. Future expansions can add multiple regions, den customization, fox coat customization, climbing, digging, stealth, prey/chase minigames, NPC schedules, controller support, inventory, quests, and a downloadable desktop build.

## Tech

Plain HTML/CSS/JavaScript + Canvas 2D. Everything runs locally in the browser.
