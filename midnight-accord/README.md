# Midnight Accord

A mobile-friendly, browser-based supernatural romance visual novel for GitHub Pages.

## Romance / player rules

- Player character can be a **woman or man**.
- Player orientation is **bisexual**.
- Romanceable cast is **women only** for either player gender.
- There are **no male/male romance routes**.
- Male NPCs can be added as friends, rivals, relatives, villains, etc., but the route system intentionally does not create romance flags for them.

## Character creator

The creator supports name, binary gender choice, skin tone, hair style, hair color, eye color, wardrobe, and personality edge. It uses a responsive CSS avatar preview so all combinations work without requiring hundreds of pre-rendered images.

## Photoreal cast

The four romanceable women use original AI-generated photoreal character art embedded in the local asset JavaScript files:

- Seraphine Vale — vampire / Accord envoy
- Nora Mercer — human occult archivist
- Liv Sable — moon-shifter courier
- Elise Rowan — witch / Ember Circle

## Story

Bellwether Bay is governed by the **Midnight Accord**, a treaty between supernatural factions and human witnesses. The protagonist is illegally marked as a supernatural Witness and develops the ability to detect deliberate lies. Episode One follows the investigation into who marked them, why their family history was erased, and which woman they trust enough to enter the hidden world beside them.

The project intentionally uses only broad supernatural-romance ingredients from the supplied reading reference—hidden supernatural society, dangerous secrets, romance across the human/supernatural boundary—and replaces its characters, plot, terminology, rules, setting, central conflict, and relationship structure with original material.

## Features

- Branching dialogue and affection points
- Four women-only romance routes
- Gender-aware player identity
- Character customization and wardrobe
- Save / load with browser `localStorage`
- Responsive mobile UI
- Embedded photoreal character and scene art
- No framework or build step

## Run locally

Open `index.html`, or serve the folder with any static web server.
