# Sno's Chaos Archive

A custom static blog/creative-project homepage built for GitHub Pages.

Live path: https://lordglyth.github.io/snos-chaos-archive/

## Files
- index.html — structure
- styles.css — all visual styling and animation
- app.js — posts, projects, search, filters, modal reader, particles, interactions

## Add a post
Open `app.js` and add another object inside the `POSTS` array using an existing post as the template.

Each post supports:
- title
- category
- date
- accent color
- excerpt
- body paragraphs
- simple HTML blocks inside body

## Add a project
Add another object inside the `PROJECTS` array.

This site is plain HTML/CSS/JS, so GitHub Pages can host it for free without a build step.
