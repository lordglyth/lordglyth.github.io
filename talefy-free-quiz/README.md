# Arcane Academy Quiz

A free, static, mobile-friendly personality quiz built as an original alternative to subscription-gated quiz funnels.

## What it does

- One-question-per-screen quiz flow
- Progress bar
- 12 original questions
- Four original result archetypes
- Animated result analysis screen
- Full result immediately
- Score breakdown and traits
- Copy result button
- Retake button
- No signup
- No email collection
- No analytics or trackers
- No subscription or payment screen
- No backend required

## Run it

Open `index.html` locally, or serve this directory through GitHub Pages.

## Files

- `index.html` — page structure
- `style.css` — responsive visual design
- `app.js` — quiz questions, scoring, results, and UI flow

This project does not use Talefy source code, trademarks as branding, proprietary artwork, or copied quiz text. It recreates the general personality-quiz interaction pattern with original content.
